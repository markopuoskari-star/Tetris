# Tetris

Yksinkertainen selaimessa toimiva Tetris-peli. Koko peli on yhdessä tiedostossa, `index.html`.

**Pelaa:** https://markopuoskari-star.github.io/Tetris/

## Ohjaus

- Tietokone: nuolet liikuttavat ja kiertävät, välilyönti pudottaa heti, P tauottaa.
- Puhelin: napautus kiertää, vedä sivulle liikuttaaksesi, vedä alas pudottaaksesi, nopea alaspyyhkäisy pudottaa heti.

## Pisteet

- 1 / 2 / 3 / 4 riviä kerralla: 100 / 300 / 500 / 800 × taso.
- Peräkkäiset 4 rivin poistot antavat kombon: +50 % kerrallaan, enintään ×3.
- Hidas pudotus 1 piste ruudulta, pikapudotus 2 pistettä ruudulta.

Parhaat tulokset tallentuvat selaimen omaan muistiin (localStorage).
